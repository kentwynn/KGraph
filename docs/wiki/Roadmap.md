# Roadmap

KGraph's roadmap stays focused on practical repo intelligence for AI coding workflows.

## Near-Term

- Better Git-aware token saving and diff context
- Smarter cross-file symbol and call relationship inference
- Stronger TypeScript path alias and package export resolution
- Richer graph filtering for large repositories

## Integrations

- Optional MCP support
- More editor/tool-call integration surfaces
- Better session capture for agents that support hooks or tool commands

## Team Workflows

- Team-friendly shared cognition workflows
- CI-friendly quality checks
- Local-first policy/reporting helpers

Team features should keep KGraph's core promise: local, inspectable, free, and no source-code upload.
